Politica de Privacidade

Em conformidade com a Lei Geral de Protecao de Dados (Lei 13.709/2018), o InfoCell trata os dados pessoais dos clientes com seguranca e transparencia.

Controlador: InfoCell Assessoria em Informatica Ltda
Dados coletados: Nome, telefone, CPF/CNPJ, email, endereco, historico de servicos, dados de pagamento.
Finalidades: Execucao de servicos tecnicos, comunicacao com o cliente, emissao de documentos, melhoria do atendimento.
Base legal: Execucao de contrato (Art. 7o, V) e consentimento do titular (Art. 7o, I).
Armazenamento: Dados criptografados AES-256-GCM no dispositivo do operador.
Seus direitos: Acesso, correcao, exclusao, portabilidade e revogacao de consentimento.
Seguranca: Criptografia de dados sensiveis, validacao de entrada, timeout de sessao, registro de auditoria.

Recursos de Seguranca Ativos: Criptografia AES-256-GCM | Validacao CPF/CNPJ/Telefone | Mascarar dados sensiveis | Timeout de sessao | Trancar tela por inatividade | Sanitizacao de inputs | Verificacao de integridade | Log de auditoria

WhatsApp Web Integrado

Acesse o WhatsApp Web diretamente pelo painel. Escaneie o QR Code com seu celular para conectar.

  1. 1. Clique no botao "Conectar WhatsApp Web" abaixo
  2. 2. Uma nova aba sera aberta com o WhatsApp Web
  3. 3. Escaneie o QR Code com seu celular (WhatsApp > Dispositivos Conectados)
  4. 4. Após conectar, volte ao painel e clique em "Verificar Conexao"
  5. 5. Pronto! Use o botao "Enviar numero" para enviar mensagens pelo Web
