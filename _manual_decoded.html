📖 Manual do Usuário - InfoCell ERP Premium

Bem-vindo ao InfoCell ERP Premium, o sistema completo de Gestão para assistência Técnica e loja. Este manual cobre todas as funcionalidades disponíveis no painel.

Visão Geral do Sistema

O InfoCell ERP Premium é um sistema integrado que gerencia todo o ciclo do seu negócio:

  • Ordens de Serviço (OS) - Criação, acompanhamento e Gestão completa de reparos
  • PDV / Caixa - Ponto de venda integrado com fiscal e parcelamento
  • CRM / Clientes - Cadastro, pipeline de vendas e Histórico de Interações
  • Financeiro - Fluxo de caixa, contas a pagar/receber e Relatórios
  • Estoque - Produtos, fornecedores e compras
  • WhatsApp Integrado - Envio automático e central de mensagens
  • Inteligencia Artificial - Diagnóstico automático e sugestoes
  • Offline / Sincronização - Funciona sem internet com Sincronização automática

🔐 Acesso e Login

Para acessar o sistema:

  1. Abra o navegador e acesse o Endereço do sistema
  2. Digite o Usuário e a senha
  3. Clique em Entrar

Credenciais padrão: admin / admin

Altere a senha iMédiatamente Após o primeiro acesso em Configurações.

após o login, o sistema exibe o Painel Geral com Visão resumida de todas as metricas importantes.

📊 Painel Geral

O Painel é a tela principal que exibé um resumo de tudo que acontece no sistema.

Funcionalidades do Painel

  • Alertas rápidos - Estoque baixo, OS atrasadas, pagamentos pendentes
  • Acesso rápido - Botões para Nova OS, Nova Venda, Novo Cliente, Scanner, IA, OS Online, Relatórios
  • Gráficos - Faturamento, OS por status, comparativo mensal
  • OS Recentes - Lista das ultimas ordens de serviço
  • Relógio ao vivo - horário atualizado no painel

Use o botao ↻ Atualizar para recarregar todos os dados do painel.

📋 Ordens de Serviço (OS)

O Módulo mais importante do sistema. Gerencia todo o ciclo de reparos e serviços.

Funções Principais

  • Criar OS - Cadastro completo com cliente, aparelho, defeito, Diagnóstico
  • Editar OS - Atualizar status, valores, Peças utilizadas
  • Preview/Visualizar - VisualizAção rápida dos dados da OS
  • Enviar WhatsApp - Compartilhar resumo da OS via WhatsApp
  • Gerar PDF - Documento formatado para Impressão ou envio
  • Excluir - Remover OS (requer confirmAção)
  • Assinatura Digital - Captura de assinatura do cliente na tela
  • Fotos do Aparelho - Upload de fotos via camera ou galeria
  • QR Code - Etiqueta com QR para o cliente acompanhar

Status das OS

StatusCorSignificado
AguardandoAmareloOS criada, aguardando atendimento
Em AndamentoAzulReparo em execucao
Aguardando PeçaLaranjaDepende de peça para continuidade
ConcluídoVerdeReparo finalizado, aguardando retirada
EntregueRoxoCliente retirou o equipamento
CanceladoVermelhoOS cancelada

Envio via WhatsApp

Na tabela de OS, clique no ícone verde do WhatsApp ao lado de cada OS para enviar automáticamente:

  • Mensagem de status atualizada
  • Resumo completo da OS em PDF
  • Lembrete de retirada

Histórico do Equipamento

O sistema rastreia todas as OS por equipamento. Ao criar uma OS para um aparelho que já foi atendido, o Histórico anterior é exibido automáticamente, incluindo:

  • Reparos anteriores
  • Peças já utilizadas
  • Garantia de serviços anteriores
  • Número de série / IMEI

💰 PDV / Caixa

Ponto de venda integrado para vendas diretas e lançamento de OS.

Funcionalidades

  • Busca de produtos - Por nome, código ou código de barras
  • Scanner de código de barras - Leitura via camera do celular
  • Formas de pagamento - Dinheiro, PIX, Cartao Credito/Debito,Boleto
  • Parcelamento - Configurável até 12x com juros
  • Desconto - Valor fixo ou percentual
  • Frete - Adicionado ao total da venda
  • NFCe - Emissão de nota fiscal eletrônica
  • Recibo - Impressão de comprovante
  • Abertura/Fechamento de Caixa - Controle de saldo diário

O PDV gera automáticamenté uma OS quando a venda envolve serviço de reparo.

👥 Clientes

Cadastro completo de clientes com Histórico integrado.

Campos do Cadastro

  • Nome, CPF/CNPJ, RG
  • Telefone (formato WhatsApp), Email
  • Endereço com busca por CEP automática
  • Data de aniversário (para envio de parabéns)
  • Tipo: Regular, VIP, Novo
  • Observações e etiquetas

Funções do Módulo

  • Preview - VisualizAção rápida com resumo
  • WhatsApp - Envio direto de mensagem
  • Excluir - Remoção com confirmAção
  • Exportar - Lista em formato texto/CSV
  • Histórico - Todas as OS e compras do cliente

Busca Inteligente

A busca global (/) encontra clientes por nome, CPF, telefone ou email em tempo real.

💬 Interações

Registro de todas as Interações com clientes: ligações, emails, reuniões, WhatsApp.

  • Crie Interações manualmente ou elas são geradas automáticamente ao enviar WhatsApp
  • Filtre por cliente, tipo ou periodo
  • Visualize o Histórico completo de contato

🔧 Serviços

Cadastro de serviços oferecidos pela loja.

Campos

  • Nome do serviço - Ex: Troca de Tela, Limpeza, FormatAção
  • Descrição - Detalhes do serviço
  • Preco - Valor cobrado
  • Tempo estimado - Prazo para execucao
  • Categoria - ClassificAção do serviço

Os serviços cadastrados aparecem como opções ao criar ou editar OS.

📦 Produtos / Estoque

Gestão completa de produtos, estoque e Preços.

Funcionalidades

  • Cadastro completo - Nome, código, barcode, marca, modelo, fornecedor
  • Preços - Custo, venda, promoção
  • Estoque - Quantidade atual, estoque mínimo, alertas
  • Catálogo de Marcas/Modelos - Base de dados de equipamentos
  • Preview - VisualizAção rápida do produto
  • WhatsApp - Enviar info do produto para cliente
  • Exportar - Lista de produtos em texto
  • Alerta de Estoque Baixo - NotificAção automática

Catálogo de Marcas e Modelos

O sistema inclui um Catálogo completo de marcas e modelos de equipamentos (smartphones, notebooks, tablets, etc). Ao cadastrar um aparelho na OS, selecione a marca e o modelo para preenchimento automático.

📝 Contratos

Emissão e Gestão de contratos de prestAção de serviço.

  • Crie contratos com cláusulas padrão ou personalizadas
  • Associe contratos a OS ou clientes
  • Gere PDF do contrato para assinatura
  • Acompanhe vigência e renovações

💵 Financeiro

Visão completa das finanças do negócio.

Funcionalidades

  • Fluxo de Caixa - Entradas e saídas do dia/mes
  • Gráficos - Faturamento mensal, por categoria
  • Filtros - Por periodo, categoria, forma de pagamento
  • Exportar PDF - Relatório financeiro completo
  • Comparativo - Mês atual vs. mes anterior

💳 Contas a Pagar / Receber

Controle de todas as contas pendentes e recebidas.

Tipos

TipoDescrição
PagarContas que a loja deve (fornecedores, aluguel, etc)
ReceberValores a receber (OS pendentes, parcelas)
  • Registre contas com vencimento, valor e categoria
  • Marque como paga/recebida com data efetiva
  • Filtre por status: Pendente, Pago, Atrasado
  • NotificAção automática para contas próximas ao vencimento

Comissoes

Cálculo e Gestão de comissoes dos vendedores/Técnicos.

  • Defina percentual de comissão por funcionário
  • comissão calculada automáticamente sobre vendas e OS
  • Relatório de comissoes por periodo
  • Possibilidade de ajuste manual

🏭 Fornecedores

Cadastro de fornecedores com dados de contato e Histórico de compras.

  • Nome, CNPJ, telefone, email, Endereço
  • Prazo de entrega médio
  • Produtos fornecidos
  • AvaliAção e Observações

🛒 Compras

Registro de compras de insumos e produtos para estoque.

  • Selecione o fornecedor
  • Adicione itens com quantidade e preco
  • O estoque é atualizado automáticamente Após confirmAção
  • Histórico de compras por fornecedor

⭐ Programa de Fidelidade

Sistema de pontos e recompensas para clientes frequentes.

  • Clientes ganham pontos a cada compra ou serviço
  • Troca de pontos por descontos ou produtos
  • Níveis: Bronze, Prata, Ouro, Platina
  • Painel de acompanhamento por cliente

🏢 Filiais

Gerenciamento de múltiplas filiais da empresa.

  • Cadastro de filiais com Endereço e dados próprios
  • Transferência de produtos entre filiais
  • Relatórios consolidados ou por filial
  • Controle de estoque separado por filial

📅 Agendamentos

Agende compromissos e serviços com clientes.

  • Data, hora, cliente e Descrição
  • NotificAção antes do horário agendado
  • Vínculo direto com OS
  • VisualizAção em lista e calendário

📆 Calendário

VisualizAção mensal/semanal/diária de todos os eventos:

  • OS criadas e concluídas
  • Agendamentos
  • Vencimentos de contas
  • aniversários de clientes
  • Compromissos pessoais

✅ Tarefas

Gerenciador de tarefas com prioridade e status.

  • Criar tarefa com título, Descrição e prioridade
  • Prioridades: Baixa, Média, Alta, Urgente
  • Marcar como concluída
  • Filtros por status e prioridade
  • Contador de tarefas pendentes na sidebar

🤝 Compromissos

Agenda de compromissos pessoais e reuniões da equipe.

  • Crie compromissos com data, hora e durAção
  • Defina recorrência (diária, semanal, mensal)
  • Lembretes automáticos

🔔 Alertas

Central de notificAções do sistema.

  • Estoque baixo - Produtos abaixo do mínimo
  • OS atrasadas - Prazo de entrega excedido
  • Contas vencendo - Pagamentos próximos ao vencimento
  • Aniversariantes - Clientes que fazem aniversário
  • Garantia expirando - serviços com garantia próxima ao fim

📉 Previsão Financeira

Projeção de entradas e saídas para os próximos meses.

  • Baseada em contas recorrentes e Histórico
  • Gráfico de Projeção mensal
  • Alertas de déficit ou superávit

📊 Relatórios Avançados

Gere Relatórios completos de qualquer Módulo do sistema.

Tipos de Relatório

  • OS - Lista completa com filtros de periodo, status, Técnico
  • Financeiro - Fluxo de caixa, receita, despesa, lucro
  • Estoque - Posição de estoque, movimentAção, giro
  • Clientes - Cadastro, frequência, ticket médio
  • Servicos - Mais realizados, faturamento por serviço
  • Compras - Histórico de compras por fornecedor
  • Fidelidade - Pontos distribuidos, resgates, ranking

Cada Relatório pode ser exportado em PDF para Impressão ou envio.

🤖 Automação

Configure Ações automáticas para poupar tempo.

Tipos de AutomAção

  • WhatsApp em Massa - Enviar lembretes, Orçamentos, boas-vindas e parabéns automáticamente
  • Lembrete de Retirada - Mensagem automática para OS concluídas ha X dias
  • AtualizAção de Status - Notifica cliente quando status muda
  • Backup automático - Backup periódico dos dados
  • Limpeza LGPD - Retenção automática de dados conforme politica

Templates de Mensagens

Edite os templates de mensagens automáticas em AutomAção > Editar Templates. Variáveis disponíveis:

  • {cliente} - Nome do cliente
  • {os} - Número da OS
  • {telefone} - Telefone do cliente
  • {status} - Status atual da OS
  • {valor} - Valor da OS

✅ Checklists

Checklists padronizados para inspeção de equipamentos.

  • Crie checklists por tipo de equipamento
  • Itens com checkbox para preenchimento rápido
  • Associe a OS para inspeção na entrada e saida
  • Histórico de checklists preenchidos

🌐 OS Online

Sistema de acompanhamento online para clientes.

  • Cliente acompanha o status da OS em tempo real
  • Link compartilhável via WhatsApp
  • Sem necessidade de login do cliente
  • Exibe status, preVisão e valores

💬 Central WhatsApp

IntegrAção completa com WhatsApp para comunicAção com clientes.

Modos

  • Central - Chat interno com Histórico de mensagens por contato
  • WhatsApp Web - Acesse o WhatsApp Web diretamente pelo painel

Funções

  • Envio direto - Clique no ícone verde do WhatsApp em qualquer tabela
  • Templates - Mensagens pré-definidas para agilizar o atendimento
  • Resumo OS - Envia resumo completo da OS formatado
  • Lembrete - Lembrete de retirada automático
  • Envio em Massa - Lembretes, Orçamentos, boas-vindas e parabéns
  • Analytics - Estisticas de envios por periodo

  1. Abrir o WhatsApp Web em uma nova aba

🧠 Central de IA

Assistente inteligente para Diagnóstico e sugestoes.

Funcionalidades

  • SuGestão de Pecas - Peças provaveis necessarias para o reparo

📜 Auditoria

Registro completo de todas as Ações realizadas no sistema.

  • Login e logout de usuários

🔒 LGPD - Privacidade

O sistema atende a Lei Geral de Protecao de Dados (LGPD).

Funcionalidades

  • Criptografia AES-256-GCM - Dados sensiveis criptografados
  • Consentimento - Banner de aceite na primeira visita
  • Retenção de Dados - Limpeza automática Após periodo Configurável
  • ExportAção - O cliente pode solicitar exportAção de seus dados
  • Exclusao - O cliente pode solicitar exclusao de seus dados
  • Politica de Privacidade - Texto completo acessivel pelo banner
  • ValidAção - VerificAção de integridade dos dados

Itens Configuraveis
