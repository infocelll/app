📷 QR Code no Link Gerado

Ao gerar um link para o cliente na aba OS Online, um QR Code aparece automaticamente ao lado do PIN e botões de compartilhamento. O cliente pode escanear o QR Code para abrir o link no celular.

🔄 Sincronização com Servidor

O dashboard agora pode sincronizar dados com um servidor remoto, permitindo usar o mesmo banco de dados em múltiplos dispositivos.

Passo a passo

1
Abra as Configurações No menu lateral, clique em Config (ícone de engrenagem).
2
Localize "Sincronização Online (Servidor)" Role a página de configurações até a seção correspondente.
3
Insira a URL do servidor Cole a URL do seu servidor Render (ou outro) no campo indicado:
https://infocelll-api.onrender.com
4
Salve e teste Clique em Salvar e depois em Testar Conexão para verificar se o servidor está acessível.
⚠ Dica: A sincronização automática ocorre a cada 5 minutos. Você também pode clicar no botão Sincronizar Agora na aba Configurações para forçar uma sincronização imediata.

Configurar senha do servidor (primeira vez)

Abra o Console do navegador (F12) e cole o comando abaixo, substituindo suasenha123 pela senha desejada:

fetch('https://infocelll-api.onrender.com/api/auth/password', { method:'POST', headers:{'Content-Type':'application/json'}, body:JSON.stringify({password:'suasenha123'}) }).then(r=>r.text()).then(console.log)

Depois vá em Config > Segurança e insira a mesma senha no campo "Senha do Servidor".

🔧 Correções Técnicas

ProblemaSolução
Erro OS não renderizava quando campo "cliente" estava vazio Código agora usa fallback o.cliente||o.clienteNome||'?' — não quebra mais a lista
Erro IndexedDB "idb_meta" não encontrado Object store agora é criado na abertura inicial do banco
Erro Service Worker falhava em file:// Registro do SW e Cache API agora pulam quando o protocolo é file://
Erro Service Worker tentava precache de sw.js inexistente Arquivo removido da lista de precache; versão do cache bumpada para v6
Melhoria QR Code não aparecia na OS Online QR Code agora é exibido automaticamente ao lado do link gerado
Melhoria Botão "Gerar Link" desabilitado Select de OS agora tem onchange para habilitar o botão
⚠ Importante: Após essas correções, pressione Ctrl+F5 para forçar o recarregamento completo dos arquivos (ignorando cache do navegador).
