Manual do Usuario - InfoCell ERP Premium

Bem-vindo ao InfoCell ERP Premium, o sistema completo de gestao para assistencia tecnica e loja. Este manual cobre todas as funcionalidades disponiveis no painel.

Visao Geral do Sistema

O InfoCell ERP Premium e um sistema integrado que gerencia todo o ciclo do seu negocio:

  • Ordens de Servico (OS) - Criacao, acompanhamento e gestao completa de reparos
  • PDV / Caixa - Ponto de venda integrado com fiscal e parcelamento
  • CRM / Clientes - Cadastro, pipeline de vendas e historico de interacoes
  • Financeiro - Fluxo de caixa, contas a pagar/receber e relatorios
  • Estoque - Produtos, fornecedores e compras
  • WhatsApp Integrado - Envio automatico e central de mensagens
  • Inteligencia Artificial - Diagnostico automatico e sugestoes
  • Offline / Sincronizacao - Funciona sem internet com sincronizacao automatica

Acesso e Login

Para acessar o sistema:

  1. Abra o navegador e acesse o endereco do sistema
  2. Digite o usuario e a senha
  3. Clique em Entrar

Credenciais padrao: admin / admin

Altere a senha imediatamente apos o primeiro acesso em Configuracoes.

Apos o login, o sistema exibe o Painel Geral com visao resumida de todas as metricas importantes.

Painel Geral

O Painel e a tela principal que exibe um resumo de tudo que acontece no sistema.

Funcionalidades do Painel

  • Alertas rapidos - Estoque baixo, OS atrasadas, pagamentos pendentes
  • Acesso rapido - Botoes para Nova OS, Nova Venda, Novo Cliente, Scanner, IA, OS Online, Relatorios
  • Graficos - Faturamento, OS por status, comparativo mensal
  • OS Recentes - Lista das ultimas ordens de servico
  • Relogio ao vivo - Horario atualizado no painel

Use o botao ↻ Atualizar para recarregar todos os dados do painel.

Ordens de Servico (OS)

O modulo mais importante do sistema. Gerencia todo o ciclo de reparos e servicos.

Funcoes Principais

  • Criar OS - Cadastro completo com cliente, aparelho, defeito, diagnostico
  • Editar OS - Atualizar status, valores, pecas utilizadas
  • Preview/Visualizar - Visualizacao rapida dos dados da OS
  • Enviar WhatsApp - Compartilhar resumo da OS via WhatsApp
  • Gerar PDF - Documento formatado para impressao ou envio
  • Excluir - Remover OS (requer confirmacao)
  • Assinatura Digital - Captura de assinatura do cliente na tela
  • Fotos do Aparelho - Upload de fotos via camera ou galeria
  • QR Code - Etiqueta com QR para o cliente acompanhar

Status das OS

StatusCorSignificado
AguardandoAmareloOS criada, aguardando atendimento

Envio via WhatsApp

Na tabela de OS, clique no icone verde do WhatsApp ao lado de cada OS para enviar automaticamente:

  • Mensagem de status atualizada
  • Resumo completo da OS em PDF
  • Lembrete de retirada

Historico do Equipamento

O sistema rastreia todas as OS por equipamento. Ao criar uma OS para um aparelho que ja foi atendido, o historico anterior e exibido automaticamente, incluindo:

  • Reparos anteriores
  • Pecas ja utilizadas
  • Garantia de servicos anteriores
  • Numero de serie / IMEI

PDV / Caixa

Ponto de venda integrado para vendas diretas e lancamento de OS.

Funcionalidades

  • Busca de produtos - Por nome, codigo ou codigo de barras
  • Scanner de codigo de barras - Leitura via camera do celular
  • Formas de pagamento - Dinheiro, PIX, Cartao Credito/Debito,Boleto
  • Parcelamento - Configuravel ate 12x com juros
  • Desconto - Valor fixo ou percentual
  • Frete - Adicionado ao total da venda
  • NFCe - Emissao de nota fiscal eletronica
  • Recibo - Impressao de comprovante
  • Abertura/Fechamento de Caixa - Controle de saldo diario

O PDV gera automaticamente uma OS quando a venda envolve servico de reparo.

Clientes

Cadastro completo de clientes com historico integrado.

Campos do Cadastro

  • Nome, CPF/CNPJ, RG
  • Telefone (formato WhatsApp), Email
  • Endereco com busca por CEP automatica
  • Data de aniversario (para envio de parabens)
  • Tipo: Regular, VIP, Novo
  • Observacoes e etiquetas

Funcoes do Modulo

  • Preview - Visualizacao rapida com resumo
  • WhatsApp - Envio direto de mensagem
  • Excluir - Remocao com confirmacao
  • Exportar - Lista em formato texto/CSV
  • Historico - Todas as OS e compras do cliente

Busca Inteligente

A busca global (/) encontra clientes por nome, CPF, telefone ou email em tempo real.

Pipeline CRM

Visualizacao Kanban do funil de vendas. Arraste os cartoes entre colunas para atualizar o estagio.

Estagios do Pipeline

EstagioDescricao
LeadContato inicial, ainda nao qualificado
ContatoPrimeiro contato realizado
OrcamentoProposta enviada ao cliente
NegociacaoEm fase de fechamento
FechadoVenda concretizada
PerdidoOportunidade nao convertida

Interacoes

Registro de todas as interacoes com clientes: ligacoes, emails, reunioes, WhatsApp.

  • Crie interacoes manualmente ou elas sao geradas automaticamente ao enviar WhatsApp
  • Filtre por cliente, tipo ou periodo
  • Visualize o historico completo de contato

Servicos

Cadastro de servicos oferecidos pela loja.

Campos

  • Nome do servico - Ex: Troca de Tela, Limpeza, Formatacao
  • Descricao - Detalhes do servico
  • Preco - Valor cobrado
  • Tempo estimado - Prazo para execucao
  • Categoria - Classificacao do servico

Os servicos cadastrados aparecem como opcoes ao criar ou editar OS.

Produtos / Estoque

Gestao completa de produtos, estoque e precos.

Funcionalidades

  • Cadastro completo - Nome, codigo, barcode, marca, modelo, fornecedor
  • Precos - Custo, venda, promocao
  • Estoque - Quantidade atual, estoque minimo, alertas
  • Catalogo de Marcas/Modelos - Base de dados de equipamentos
  • Preview - Visualizacao rapida do produto
  • WhatsApp - Enviar info do produto para cliente
  • Exportar - Lista de produtos em texto
  • Alerta de Estoque Baixo - Notificacao automatica

Catalogo de Marcas e Modelos

O sistema inclui um catalogo completo de marcas e modelos de equipamentos (smartphones, notebooks, tablets, etc). Ao cadastrar um aparelho na OS, selecione a marca e o modelo para preenchimento automatico.

Contratos

Emissao e gestao de contratos de prestacao de servico.

  • Crie contratos com clausulas padrao ou personalizadas
  • Associate contratos a OS ou clientes
  • Gere PDF do contrato para assinatura
  • Acompanhe vigencia e renovacoes

Financeiro

Visao completa das finances do negocio.

Funcionalidades

  • Fluxo de Caixa - Entradas e saidas do dia/mes
  • Graficos - Faturamento mensal, por categoria
  • Filtros - Por periodo, categoria, forma de pagamento
  • Exportar PDF - Relatorio financeiro completo
  • Comparativo - Mes atual vs. mes anterior

Contas a Pagar / Receber

Controle de todas as contas pendentes e recebidas.

Tipos

TipoDescricao
PagarContas que a loja deve (fornecedores, aluguel, etc)
ReceberValores a receber (OS pendentes, parcelas)
  • Registre contas com vencimento, valor e categoria
  • Marque como paga/recebida com data efetiva
  • Filtre por status: Pendente, Pago, Atrasado
  • Notificacao automatica para contas proximas ao vencimento

Comissoes

Calculo e gestao de comissoes dos vendedores/tecnicos.

  • Defina percentual de comissao por funcionario
  • Comissao calculada automaticamente sobre vendas e OS
  • Relatorio de comissoes por periodo
  • Possibilidade de ajuste manual

Fornecedores

Cadastro de fornecedores com dados de contato e historico de compras.

  • Nome, CNPJ, telefone, email, endereco
  • Prazo de entrega medio
  • Produtos fornecidos
  • Avaliacao e observacoes

Compras

Registro de compras de insumos e produtos para estoque.

  • Selecione o fornecedor
  • Adicione itens com quantidade e preco
  • O estoque e atualizado automaticamente apos confirmacao
  • Historico de compras por fornecedor

Programa de Fidelidade

Sistema de pontos e recompensas para clientes frequentes.

  • Clientes ganham pontos a cada compra ou servico
  • Troca de pontos por descontos ou produtos
  • Niveis: Bronze, Prata, Ouro, Platina
  • Painel de acompanhamento por cliente

Filiais

Gerenciamento de multiplas filiais da empresa.

  • Cadastro de filiais com endereco e dados proprios
  • Transferencia de produtos entre filiais
  • Relatorios consolidados ou por filial
  • Controle de estoque separado por filial

Agendamentos

Agende compromissos e servicos com clientes.

  • Data, hora, cliente e descricao
  • Notificacao antes do horario agendado
  • Vinculo direto com OS
  • Visualizacao em lista e calendario

Calendario

Visualizacao mensal/semanal/diaria de todos os eventos:

  • OS criadas e concluidas
  • Agendamentos
  • Vencimentos de contas
  • Aniversarios de clientes
  • Compromissos pessoais

Tarefas

Gerenciador de tarefas com prioridade e status.

  • Criar tarefa com titulo, descricao e prioridade
  • Prioridades: Baixa, Media, Alta, Urgente
  • Marcar como concluida
  • Filtros por status e prioridade
  • Contador de tarefas pendentes na sidebar

Compromissos

Agenda de compromissos pessoais e reunioes da equipe.

  • Crie compromissos com data, hora e duracao
  • Defina recorrencia (diaria, semanal, mensal)
  • Lembretes automaticos

Alertas

Central de notificacoes do sistema.

  • Estoque baixo - Produtos abaixo do minimo
  • OS atrasadas - Prazo de entrega excedido
  • Contas vencendo - Pagamentos proximos ao vencimento
  • Aniversariantes - Clientes que fazem aniversario
  • Garantia expirando - Servicos com garantia proxima ao fim

Previsao Financeira

Projecao de entradas e saidas para os proximos meses.

  • Baseada em contas recorrentes e historico
  • Grafico de projecao mensal
  • Alertas de deficit ou superavit

Relatorios Avancados

Gere relatorios completos de qualquer modulo do sistema.

Tipos de Relatorio

  • OS - Lista completa com filtros de periodo, status, tecnico
  • Financeiro - Fluxo de caixa, receita, despesa, lucro
  • Estoque - Posicao de estoque, movimentacao, giro
  • Clientes - Cadastro, frequencia, ticket medio
  • Servicos - Mais realizados, faturamento por servico
  • Compras - Historico de compras por fornecedor
  • Fidelidade - Pontos distribuidos, resgates, ranking

Cada relatorio pode ser exportado em PDF para impressao ou envio.

Automacao

Configure acoes automaticas para poupar tempo.

Tipos de Automacao

  • WhatsApp em Massa - Enviar lembretes, orcamentos, boas-vindas e parabens automaticamente
  • Lembrete de Retirada - Mensagem automatica para OS concluidas ha X dias
  • Atualizacao de Status - Notifica cliente quando status muda
  • Backup Automatico - Backup periodico dos dados
  • Limpeza LGPD - Retencao automatica de dados conforme politica

Templates de Mensagens

Edite os templates de mensagens automaticas em Automacao > Editar Templates. Variaveis disponiveis:

  • {cliente} - Nome do cliente
  • {os} - Numero da OS
  • {telefone} - Telefone do cliente
  • {status} - Status atual da OS
  • {valor} - Valor da OS

Checklists

Checklists padronizados para inspecao de equipamentos.

  • Crie checklists por tipo de equipamento
  • Itens com checkbox para preenchimento rapido
  • Associate a OS para inspecao na entrada e saida
  • Historico de checklists preenchidos

OS Online

Sistema de acompanhamento online para clientes.

  • Cliente acompanha o status da OS em tempo real
  • Link compartilhavel via WhatsApp
  • Sem necessidade de login do cliente
  • Exibe status, previsao e valores

Central WhatsApp

Integracao completa com WhatsApp para comunicacao com clientes.

Modos

  • Central - Chat interno com historico de mensagens por contato
  • WhatsApp Web - Acesse o WhatsApp Web diretamente pelo painel

Funcoes

  • Envio direto - Clique no icone verde do WhatsApp em qualquer tabela
  • Templates - Mensagens pre-definidas para agilizar o atendimento
  • Resumo OS - Envia resumo completo da OS formatado
  • Lembrete - Lembrete de retirada automatico
  • Envio em Massa - Lembretes, orcamentos, boas-vindas e parabens
  • Analytics - Estisticas de envios por periodo
  • QR Code - Gere QR Code para contato rapido

WhatsApp Web

Na Central WhatsApp, clique na aba "WhatsApp Web" para:

  1. Abrir o WhatsApp Web em uma nova aba
  2. Escanear o QR Code com o celular
  3. Enviar numeros diretamente pelo painel

Central de IA

Assistente inteligente para diagnostico e sugestoes.

Funcionalidades

  • Diagnostico Automatico - IA sugere diagnostico baseado no defeito informado
  • Sugestao de Pecas - Pecas provaveis necessarias para o reparo
  • Estimativa de Custo - Valor estimado do reparo
  • Monitor de IA - Acompanhe as respostas e acertos da IA
  • Modo Offline - Biblioteca local de diagnosticos quando sem internet

Funcionarios

Cadastro e gestao da equipe.

  • Nome, cargo, telefone, email
  • Percentual de comissao
  • OS atribuidas e historico
  • Desempenho por periodo

Auditoria

Registro completo de todas as acoes realizadas no sistema.

  • Criacao, edicao e exclusao de registros
  • Login e logout de usuarios
  • Envios de WhatsApp
  • Exportacao de dados
  • Filtros por data, usuario e tipo de acao

LGPD - Privacidade

O sistema atende a Lei Geral de Protecao de Dados (LGPD).

Funcionalidades

  • Criptografia AES-256-GCM - Dados sensiveis criptografados
  • Consentimento - Banner de aceite na primeira visita
  • Retencao de Dados - Limpeza automatica apos periodo configuravel
  • Exportacao - O cliente pode solicitar exportacao de seus dados
  • Exclusao - O cliente pode solicitar exclusao de seus dados
  • Politica de Privacidade - Texto completo acessivel pelo banner
  • Validacao - Verificacao de integridade dos dados

Configuracoes

Personalize o sistema conforme sua necessidade.

Itens Configuraveis

  • Dados da Empresa - Nome, CNPJ, endereco, telefone, logo
  • Tema - Escolha entre 6 temas visuais
  • Senha - Altere a senha de acesso
  • Backup - Exporte/importe dados completos
  • Backup com Fotos - Inclui fotos dos aparelhos
  • WhatsApp - Numero padrao para envios
  • Automacao - Ative/desative lembretes automaticos
  • LGPD - Configure retencao de dados
  • Moeda - Simbolo e formatacao de valores
  • Impressora - Configuracao de impressao de OS e recibos
